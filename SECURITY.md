# Política de segurança

Não abra uma issue pública com tokens, dados pessoais ou detalhes que permitam exploração. Envie o relato pelo formulário em `https://gbm-finance.com/fale-conosco.html`, informe o componente afetado, impacto e passos mínimos para reprodução, sem incluir dados reais de usuários.

Credenciais expostas devem ser revogadas no fornecedor imediatamente. A equipe não solicitará senha, código de autenticação ou acesso remoto ao dispositivo.
